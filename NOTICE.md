# Notices and source credits

The OCGE Data Base is built from the public sources below. Raw source files are not in this repository; each one is listed in `dataset/data/MANIFEST.csv` with its link, version and SHA-256. Each source keeps its own terms. Published values in the data base are derived (aggregated, balanced and adjusted), and every source is credited here.

Sources whose terms do not allow redistribution are used as build inputs only: their files are never shipped, and users who rebuild must obtain them from the publisher under its terms.

**WTO-OECD TiSMoS** (ODbL 1.0): the data base uses mode-of-supply shares from TiSMoS as one input to the services split. This use is treated as insubstantial, and TiSMoS is credited here: Contains information from the WTO-OECD Trade in Services by Mode of Supply (TiSMoS) dataset, made available under the Open Database License (ODbL) v1.0.

**EXIOBASE** (CC BY-SA 4.0) is used only for internal comparison reports; no EXIOBASE value enters the data base.
