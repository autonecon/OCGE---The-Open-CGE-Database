- **Download date / origin:** 2022_SML.csv/2017_SML.csv copied 2026-10-20 from an earlier internal build, earlier-build/sources/oecd (originally downloaded by the dataset agent); docs downloaded 2026-10-20

- **Valuation basis / concept:** basic prices; re-exports/re-imports removed; trade first balanced at FOB (ICIO 2023 methods paper pp.16-17, docs/)
