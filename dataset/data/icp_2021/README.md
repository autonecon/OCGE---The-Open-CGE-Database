# World Bank International Comparison Program (ICP) 2021 results (DataBank extract)

- **Folder:** `data/icp_2021/`
- **Source page:** [https://www.worldbank.org/en/programs/icp](https://www.worldbank.org/en/programs/icp)
- **Download URL / API:** https://databank.worldbank.org/source/icp-2021 (extract made in repo-audit; file icp_databank_3a11040d.csv)
- **Version:** ICP 2021 cycle, published 2024
- **Download date / origin:** copied 2026-10-20 from an internal working folder
- **Licence:** CC BY 4.0
- **Coverage (2022 or year-rule fallback):** 145 of 159 single economies (2021; year rule: latest earlier year, used for checks only)
- **Units:** PPPs, price levels, expenditure in local currency and PPP USD
- **Valuation basis / concept:** expenditure at purchasers prices (ICP)
- **How it is used (PLAN.md stage):** Stage (k): like-with-like check of household and government expenditure levels and price levels; never a fill value.
