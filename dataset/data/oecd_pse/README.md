# OECD Producer and Consumer Support Estimates

- **Folder:** `data/oecd_pse/`
- **Source page:** [https://www.oecd.org/en/topics/sub-issues/producer-and-consumer-support-estimates.html](https://www.oecd.org/en/topics/sub-issues/producer-and-consumer-support-estimates.html)
- **Download URL / API:** https://sdmx.oecd.org/public/rest/data/ (DF_MONEVA, DF_COMPSE, PSE all)
- **Version:** Agricultural Policy Monitoring and Evaluation, 2022 values
- **Download date / origin:** 2026-10-20
- **Licence:** OECD; CC BY 4.0 since 1 July 2024
- **Coverage (2022 or year-rule fallback):** 29 areas (EU as one) = 53 regions; others zero support (GTAP practice)
- **Units:** national currency / USD million
- **Valuation basis / concept:** transfer values by PSE category
- **How it is used (PLAN.md stage):** Stage (f): domestic agricultural support as GTAP does (Aguiar et al. 2022 p.10). OECD_DF_PSE_CGE_2022.csv is misnamed and NOT used.
