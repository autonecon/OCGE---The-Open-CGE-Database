- **Folder:** `data/nbs_census_chn/`
- **Download URL / API:** https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/indexch.htm
- **Version:** 2020 Population Census (7th) long-form tables 4-4 and 4-6
- **Download date / origin:** 2026-10-20 via Cloudflare WARP proxy; see FETCH_NOTES.md
- **Licence:** NBS public statistical publication; small extracts with citation; not redistributed publicly
- **Coverage:** China by province; employed persons by sex x industry division (B0404) and by sex x occupation sub-major group (B0406); margins only, no occupation x industry cross table
- **Units:** persons (long-form ~10% sample, not grossed up; use as shares)
